# Health Track

A contribution to a centralized medical follow-up platform using Spring Cloud services and an Angular dashboard. The project connected a business interface, service discovery and application authentication.

**My role:** Full-Stack Developer · E-AMBITION internship · July–September 2025  
**Author:** [Nizar Gassab](https://github.com/nizargassab)

[View project](https://nizar-gassab-portfolio.vercel.app/projets/health-track/) · [Portfolio case study](https://nizar-gassab-portfolio.vercel.app/projets/health-track/) · [LinkedIn](https://www.linkedin.com/in/nizar-gassab-b872b5244/)

## What I worked on

### 1. Authentication

Worked on the JWT authentication module for the platform.

### 2. Reusable UI

Created reusable Angular components for the medical follow-up dashboard.

### 3. Service environment

Worked with Spring Cloud, API Gateway, Eureka and Docker containerization.
